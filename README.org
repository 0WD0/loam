#+title: Loam

Loam is an EDN-native web framework for semantic Org knowledge bases.

It consumes structured EDN documents, usually produced by =ox-edn=, and turns them into indexed, link-aware, extensible web experiences.

* Design goals

- EDN-native: no Markdown conversion layer
- Data-first: every stage is inspectable Clojure data
- Extensible: renderers, indexers, layouts, hooks, and assets are replaceable
- Static-first: works without a server, but does not prevent interactive CLJS frontends
- Org-aware: preserves IDs, custom IDs, targets, radio targets, fuzzy links, backlinks

* Quick start

#+begin_src bash
npm install
bb test

bb -cp src -m loam.site \
  --edn-dir /path/to/edn \
  --output-dir build/site \
  --url-prefix /notes/
#+end_src

Or with Make:

#+begin_src bash
make site EDN_DIR=/path/to/edn SITE_DIR=build/site
make serve
#+end_src

If you are using the sibling =ox-edn= project:

#+begin_src bash
# Uses /home/disk/Dev/ox-edn/build/edn by default.
make site-ox-edn SITE_DIR=build/ox-edn-site
make serve SITE_DIR=build/ox-edn-site
#+end_src

* Current static output

The default static build emits:

- =index.html=: home page with grouped sidebar and search UI
- =notes/<slug>/index.html=: one page per EDN document
- =index.edn=: public navigation/link/backlink/search/graph index
- =search-index.json=: browser-friendly search data
- =graph.edn= and =graph.json=: graph nodes and edges
- =assets/site.css= and =assets/search.js=: default theme assets
- =assets/loam-treesitter.*= and =assets/tree-sitter/**=: default Tree-sitter highlighter assets

The sidebar groups pages by EDN relative directory, so =daily/*.edn= and other subtrees become sections automatically.

* Architecture

Loam is split into small replaceable layers:

| Namespace | Responsibility |
|-----------+----------------|
| =loam.core= | System map, extension installation, hooks |
| =loam.ast= | AST traversal, title/text extraction, source helpers |
| =loam.index= | IDs, custom IDs, targets, links, backlinks, URL resolution |
| =loam.render= | Registry-based AST -> Hiccup rendering |
| =loam.html= | Minimal Hiccup -> HTML serialization |
| =loam.json= | Minimal JSON serialization for static artifacts |
| =loam.graph= | Graph data extension |
| =loam.theme.default= | Default layouts, grouped sidebar, search UI, CSS/JS assets |
| =loam.search= | Search index extension |
| =loam.site= | Static site builder / CLI |

The important design choice: rendering is not a giant closed =case= owned by the framework. It is a registry in the system map:

#+begin_src clojure
(:renderers system)
;; => {:paragraph fn, :headline fn, :link fn, ...}
#+end_src

Extensions can override one node type without forking the renderer.

* Extension shape

Extensions are plain maps:

#+begin_src clojure
{:id :my/theme
 :renderers {:paragraph (fn [ctx node] ...)}
 :inline-types #{:my-inline-node}
 :indexers [(fn [index documents] ...)]
 :layouts {:page (fn [ctx document] ...)}
 :assets {"assets/theme.css" "body { ... }"}
 :asset-files {"assets/logo.svg" "resources/logo.svg"}
 :head [(fn [ctx current-url]
          [[:link {:rel "stylesheet" :href "/assets/theme.css"}]])]
 :hooks {:site/built [(fn [event] event)]}}
#+end_src

Install them with =loam.core/create-system= or =loam.defaults/create-system=:

#+begin_src clojure
(require '[loam.defaults :as loam])

(def system
  (loam/create-system {:extensions [my-extension]}))
#+end_src

* Tree-sitter WASM highlighting

Loam's default system highlights Org src blocks in the browser with Tree-sitter WASM. If you build a custom system, install the extension explicitly:

#+begin_src clojure
(require '[loam.defaults :as loam]
         '[loam.highlight.treesitter.wasm :as ts-wasm])

(def system
  (loam/create-system
   {:extensions
    [(ts-wasm/extension
      {:languages
       {:clojure {:aliases ["clj" "cljs" "cljc" "edn"]
                  :wasm "/assets/tree-sitter/languages/tree-sitter-clojure.wasm"
                  :query "/assets/tree-sitter/queries/clojure/highlights.scm"}}})]}))
#+end_src

The extension:

- overrides =:src-block= rendering with =data-loam-treesitter= markers
- writes =assets/loam-treesitter.css=
- writes =assets/loam-treesitter.js=
- writes =assets/loam-treesitter.json= language manifest
- copies Tree-sitter runtime/parser/query assets from npm packages through Loam's =:asset-files= extension point
- injects its CSS and module script through Loam's =:head= extension point

Install npm dependencies before building a site with the default Tree-sitter extension:

#+begin_src bash
npm install
#+end_src

The generated site receives assets copied from =node_modules=:

#+begin_example
assets/tree-sitter/tree-sitter.js                         <- web-tree-sitter
assets/tree-sitter/tree-sitter.wasm                       <- web-tree-sitter
assets/tree-sitter/languages/tree-sitter-clojure.wasm     <- @yogthos/tree-sitter-clojure
assets/tree-sitter/languages/tree-sitter-javascript.wasm  <- @vscode/tree-sitter-wasm
assets/tree-sitter/languages/tree-sitter-typescript.wasm  <- @vscode/tree-sitter-wasm
assets/tree-sitter/languages/tree-sitter-python.wasm      <- @vscode/tree-sitter-wasm
assets/tree-sitter/queries/*/highlights.scm               <- grammar npm packages
assets/tree-sitter/licenses/*.txt                         <- npm package licenses
#+end_example

Keep =web-tree-sitter= and language WASM ABI versions compatible when replacing or adding grammars.

* Examples

Override paragraph rendering:

#+begin_src clojure
(def paragraph-extension
  {:id :example/paragraph
   :renderers
   {:paragraph (fn [ctx node]
                 [[:p.lead (loam.render/text-content node)]])}})
#+end_src

Add an index section:

#+begin_src clojure
(def word-count-extension
  {:id :example/word-count
   :indexers
   [(fn [idx documents]
      (assoc idx :word-count
             (reduce + (map #(count (re-seq #"\\S+" (loam.ast/text (:ast %))))
                            documents))))]})
#+end_src

Replace the page layout:

#+begin_src clojure
(def layout-extension
  {:id :example/layout
   :layouts
   {:page (fn [ctx document]
            [:html
             [:body
              [:main
               (loam.render/render-document ctx (:ast document))]]])}})
#+end_src
